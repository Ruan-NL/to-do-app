# To-Do List Simples

Uma aplicação simples de lista de tarefas (To-Do List) desenvolvida utilizando apenas HTML e CSS. Este projeto demonstra como criar uma interface funcional para gerenciar tarefas com prioridades e marcação de conclusão.

## Funcionalidades

- **Campo de Entrada**: Permite digitar a descrição da tarefa.
- **Seletor de Prioridade**: Opções para definir a urgência da tarefa (Alta, Média ou Baixa).
- **Lista de Exibição**: As tarefas aparecem dinamicamente na lista (neste exemplo, as tarefas são pré-definidas no HTML).
- **Ação de Conclusão**: Checkbox para marcar a tarefa como finalizada, aplicando estilo de riscado.
- **Estilização Condicional**: Cores e elementos visuais que mudam conforme a prioridade da tarefa (vermelho para alta, amarelo para média, verde para baixa).

## Tecnologias Utilizadas

- **HTML**: Estrutura da página e elementos da interface.
- **CSS**: Estilização visual, incluindo responsividade e efeitos condicionais.

## Como Usar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Interaja com a lista de tarefas: marque os checkboxes para concluir tarefas e observe as mudanças visuais baseadas na prioridade.

## Estrutura do Projeto

- `index.html`: Arquivo principal contendo a estrutura HTML e estilos CSS inline.

## Observações

Este projeto é uma demonstração educacional focada em HTML e CSS. Para adicionar funcionalidades dinâmicas (como criar novas tarefas em tempo real), seria necessário JavaScript. As tarefas exibidas são exemplos estáticos definidos no código HTML.
